# app04 — Split-Stage Action Stream & MenuPopover

## HTML sandbox · A thought rises into an action

Build an app whose navigation makes a transformation legible: a sentence is captured, reviewed as a focus action, decomposed and given a receipt. The phone's frozen r3/v02 capture is the origin; after Fold, tab-local journeys retain separate histories while a **two-stage source/action canvas** makes the next move clear. On macOS, a real app-style menu-bar popover can handle capture, one completion and model selection without opening a window, yet can hand the same selection to a workspace and back. This is not a deep modal drawer, a lateral pocket deck or a command-search lens.

This prompt is complete Stage 1 design direction for a self-contained HTML sandbox, not SwiftUI/product source. Use synthetic memory-only records, no real microphone, media/audio APIs, personal data, network requests, analytics, real model invocation or external assets/fonts. Direction coordinates: **VS-005 Zen Paper Checklist with VS-003 Precision Acoustic & AI Studio**, **CL-006 Luminous Paper with a restrained CL-003 cyan action accent**. Use layout-navigation, motion-interaction, glass-material and typography-copy. **X:** one active action/object is P0, source provenance and tab switching P1, queue/receipt/filter P2, export/models P3. **Y:** source collapses while one action stage unfolds, with per-tab history rather than a global stack. **Z:** solid content planes at 0, static aura behind functional glass, optical tab/action chrome at 10 and unfiltered controls at 11, transient settings/receipt at 20. No final AppTheme selection is implied.

## After Fold: a tab-local transformation, not a permanent tabbed root

Fold opens a compact, in-place branch with direct **Todo List** and **Settings** choices; “最近速记” is a closed secondary branch. Entering Todo or Notes reveals native app navigation for three content destinations: 录音 / 待办 / 速记. This is a **post-Fold** navigation state, not a tab bar pasted onto the frozen opening screen. Selecting 录音 hides that chrome and restores the exact capture composition. Reopening Fold restores the last selected journey without resetting its detail/history. Each tab owns selection, scroll and pushed detail; Back never consumes a different tab's history.

At mobile size, non-capture content has 24px side margins, a modest native Back/title row at y=72, a **source stage** y=136..252 and an **action stage** y=304..660. A 56px-high functional glass navigation pill at x=24,y=722,w=342 remains separated from content and respects the 34px home-indicator area. There is no extra record pill beside it while Todo/Notes owns the P0. Main recording is reached through the actual capture destination, never by an accidental background press. The source/action gap is 52px: different pace layers, not a row of cards.

**Source stage:** collapsed by default to a 13px provenance label and one short source summary, never a second full transcript repeating the active object below. A disclosure opens the originating synthetic note temporarily in that footprint. Collapse it again when choosing another task. Expanded source and expanded secondary queue are mutually exclusive, preserving at most three visual groups (source, active action, navigation). If no capture result exists, show “来自语音收件箱” as neutral provenance, not fabricated content.

**Todo action stage:** the P0 focus sits deliberately in the **lower half**, around x=24,y=356,w=342. “整理会议决定” uses 31/650/38. A 24px circular checkring in a 44px semantic button aligns at its leading edge; this is the only prominent completion action. “语音拆解成三步” is a plain secondary action under the focus, not a second bright button. “其余 2 项” is a collapsed action-stream disclosure. Opening it replaces the focus body with borderless selectable task rows and status filter 待处理 / 执行中 / 已完成; do not stack the entire list below the focus. Selection changes the active task ID, source provenance and runner binding together.

**Action details:** todo_detail pushes within the active content tab, reusing the action-stage footprint. Its source stage remains collapsed. Show three semantic action rows “确认输入 / 复核摘要 / 留下回执”, a small acceptance condition and a single Run action. Checking a child updates parent progress, not the source note. Run opens the receipt only after explicit review; no automatic execution on voice release. Back returns to the actual selected source route, including the Notes tab when a note was converted; the declared todo_list is the history-empty fallback. Switching away and back restores this detail, not a new overview.

**Notes journey:** upper source stage holds a single selected note date/title; lower stage holds its short preview and one P0 Convert action. “所有速记” temporarily replaces preview with a three-row synthetic list. Selecting a note updates both preview and ID; recent filtering is P2 in a collapsed menu, export P3 in overflow, New P1 returns to frozen recording. **Settings/models:** Fold Settings or an app overflow opens settings_sheet at medium 45vh or large 80vh, with explicit height/max-height, a grabber, an accessible expand/collapse button and independently scrolling opaque body. “本地模型 · 就绪” and “云端模型 · 未配置” are informational rows. Selecting local commits model_local and dismisses to the same content tab/root with a specific next-recording consequence. No key field, credentials or pretend connect request. “查看模型路由” is P2; it opens runner_status and suspends the settings sheet. Closing that receipt restores settings and its opener focus; closing settings then restores the caller tab.

**Runner:** a compact maximum-342px receipt dialog on mobile, max-height 45vh, not another full dashboard. It shows one selected task's accepted/running/completed phase and a concise receipt. Refresh updates that phase; Close/outside/Escape dismisses only this presentation. Background tab strip, source gesture and recorder become inert under a modal. Completed receipt remains available after dismissal/navigation.

## macOS: a useful menu bubble, not a miniature phone

## Recording, running and cancellation: every visible state works

Idle → Listening begins on primary pointer-down with pointer capture. Show one synthetic sentence and seven bars at deterministic distinct phases, never real voice input. Pointer-up/release → Refining immediately, stop live bars and update the existing feedback line. After 900ms → Done, show “整理发布决定，确认下一步行动。” and commit voice_capture exactly once. Done allows result promotion; another hold starts a fresh capture while retaining old notes. Todo intent produces a reviewable draft; it does not skip details, fabricate a runner execution or create another task on every render.

Pointercancel, lost pointer capture, page hidden, window blur and Escape cancel uncommitted recording/refinement, invalidate timers and return to Idle with no appended note or steps. Preserve prior committed data. Reentry during Refining is ignored and the synthetic click following pointer-up cannot restart Listening. Focused Space down/up is hold parity; Enter/assistive activation toggles start/stop for non-hold access. ⌥Space and ⌥⇧Space choose text/Todo only while this page is focused, outside editable text fields; ignore repeated keydown. There is no real OS microphone or shortcut registration.

Complete shows “已完成 · 可撤销”, updates the queue and supports Undo for five seconds. Decompose is idempotent: the same parent cannot accumulate six/nine children. Child checkrings update progress without claiming an AI execution. Explicit Run creates accepted→running→completed states at deterministic 600ms simulated phase ticks; Refresh advances/refreshes the one receipt without duplicate completion. A local state failure has an inline retry, not a fictional cloud outage. Model selection changes only synthetic next-capture routing. Export preview includes only synthetic records and requires no clipboard read or request. Empty Todo has a plain return-to-capture action; no-result Notes has Clear filter; no empty placeholder dashboard.

Back/Escape priority is uncommitted recorder, top receipt, settings, tab-local detail, post-Fold navigation, menu popover. Outside tapping dismisses only the current transient layer. Modal layers trap focus and inert their background, then restore exact opener focus; hidden tabs and workspaces have no tab stops. The active source's upward gesture cannot fire through a sheet. The home-indicator area reserves 34px of interaction clearance; list scroll does not promote a result. Only the Done sentence's explicit gesture surface handles upward promotion.

Respect prefers-reduced-motion: static seven unequal bars instead of looping animation, no source-to-action spring, no smooth scroll/parallax, immediate selection or ≤100ms fade. The promotion's semantic result remains identical without motion. Reduce Transparency uses solid L1 chrome. Enlarged text wraps and expands/scrolls source/action/overlay bodies instead of clipping titles or shrinking font; preserve minimum target sizes. Use polite live-region state receipts, not an announcement on each waveform frame. Hover is supplemental and every action has keyboard/pointer/touch parity.
