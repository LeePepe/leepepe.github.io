## A complete draft-to-action transaction

Inside the console's own key-hint area show “Hold Option+Space · Text”, “Option+Shift+Space · Todo”, “Escape · Cancel”. Default pointer intent is Todo, explicitly captioned “Todo capture”; Option+Space explicitly selects Text for that run, Option+Shift+Space explicitly selects Todo. These are focused-sandbox shortcuts only, not global macOS registration. Read physical Space plus modifiers, snapshot intent once, ignore repeat and finish on Space keyup regardless of Option-release order. Holding Capture uses pointer capture; ordinary pointerup anywhere completes. Enter/Space activation on the focused primary button provides a start/stop toggle alternative. Suppress post-hold click.

Idle → **Listening**: seven 4px round-ended bars at 4px gaps move through heights 6/11/19/28/19/11/6px at 120ms phase intervals; show Listening and tabular 00:01. Synthetic phrase: “For the sample picnic, choose a shaded spot, check the route, and pack reusable cups.” As words arrive, form the one parent “Plan the sample picnic” and the three provisional child lines “Choose a shaded spot”, “Check the route”, “Pack reusable cups”. Use 160ms opacity reveals, not random real-time AI claims. Draft content cannot yet be completed, scheduled or added.

Release → **Refining** retains the provisional parent with “Checking the three steps,” settles seven bars to 5px and spends 1000ms reconciling the deterministic draft. Block duplicate Add. **Done in Todo mode**: one parent “Prepare the sample picnic” and exactly three finalized substeps above. Sole P0 changes in-place from Capture to “Add 1 task”; the parent card has no competing filled Add button. Explicit Add writes one capture-ID-keyed task into session memory, reports “Added 1 task with 3 steps,” and reveals the collection disclosure. Duplicate activation cannot add again. The promoted action then becomes “Open task,” taking the selected inspector view; New capture remains quiet in More.

**Done in Text mode**: replace the provisional task card with one solid note “Choose a shaded spot, check the route, and pack reusable cups for the sample picnic.” P0 becomes Copy note, not Add. Only explicit Copy writes the clipboard; on denial select full text with “Text selected; press Command+C.” Switching to another intent cannot silently convert a committed note. Preserve committed notes separately in session memory, accessible via the collection's local Notes lens only on explicit request; do not add another permanent tab bar.

After an explicit Add, the parent/child circular checkrings become semantic buttons with reversible `aria-pressed`. The parent marks all children complete; unchecking the parent restores all to incomplete. Individual steps update “1 of 3 steps complete”; parent becomes complete only when all three complete, with partial state stated in its accessible label. `Command+Z` undoes the most recent Add or completion transaction, with a clear receipt and no loss of raw phrase. No runner, scheduler or network is invoked. `Command+Shift+L` opens the Todo collection at rest, Up/Down changes one highlighted row, Return selects it and replaces the stage/inspector. `ArrowRight` on the selected child disclosure expands that child, `ArrowLeft` folds it; only one child detail can be open. “What I said” reveals the source phrase in-place, not in another glass card. More holds optional mock scheduling details and a seeded “Refinement unavailable” case. On failure retain raw phrase and provisional children, prevent Add, and offer Retry, which only re-runs local Refining. Escape at rest closes More, then child/raw disclosure, then collection/workspace, restoring the initiating focus. `Command+Return` always opens workspace at rest, never adds a task; focused Return on Add performs that transaction only.

Escape during Listening/Refining cancels first: invalidate run token, stop all word/preview/refinement callbacks, remove uncommitted draft children, restore prior committed selection or Idle, announce “Capture cancelled” and focus Capture. Pointercancel, lost capture, page hiding and real blur also cancel; a later release/callback is inert. Collection selection, scheduling and navigation cannot mutate an active recording. Never leave a ghost task from a cancelled draft.
