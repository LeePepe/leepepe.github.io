## Commission and coordinate lock
Design an interactive VoxPocket Todo screen as a quiet invitation: one action suspended above a closed pocket of everything else. Deliver a self-contained HTML sandbox later; this document is the complete design instruction, not implementation code. Coordinates: mobile-primary with an independently composed desktop peer; VS-005 Zen Paper Checklist with VS-003 acoustic restraint; CL-006 paper adapted to VoxPocket cyan. ## Content, selection and completion
All content is fictional and local. Initial nonfocus tasks: pending “校对月湾故事”, running “生成纸舟摘要”, done “归档示例色板”. Status menu options “全部 / 待处理 / AI 执行中 / 已完成” actually filter these nonfocus siblings; the hero is explicitly outside this scope and never duplicated in the list. Counts are computed from state. Task body selects details; the separate circular button toggles completion using aria-pressed, never raw checkbox input. A complete press draws a check in 160ms, gently fills the ring in 100ms, then lifts the sentence 4px and settles at 70% ink in 240ms. Keep the hero in place until the user chooses the next action; no automatic surprise promotion. Undo is inline for 5s and also available in detail afterward. Undo cancels pending removal timers; completed filter updates immediately without losing keyboard focus.

Mobile selection presents a solid-content sheet at y402 with 28px top corners, extending to a full detent y96 by grabber or explicit “展开详情”. Desktop inspector shows the same selected record, not another task copy in a glass card. Close/Escape returns focus to the originating row; completion button events never open detail. Notes, runner and children are mutually exclusive detail disclosures. Runner starts only after “运行这三步”; simulated status “待命 → 排队 → 执行第 1/3 步 → 第 2/3 步 → 第 3/3 步 → 完成”, 700ms per step, with Stop and Retry. Never auto-complete a task after merely generating text.

## Voice journey
Idle has seven resting 3×8px bars, not an endlessly animated ornament. Pointer hold on voice for 160ms enters Listening; captured release enters Refining for 800ms, then Done preview. Short tap instead starts Listening in toggle mode; second tap stops. Space held while voice is focused mirrors hold/release; Enter toggles. Suppress the click following a hold. Listening displays the synthetic sentence “准备星桥演示：收集三条反馈，归成两类，写一段结论”. Refining resolves into exactly 3 child action items: “收集三条反馈”, “将反馈归成两类”, “写一段结论”. Done offers plain “加入收件箱” and “重说”; accepting creates one parent with those three children, once per session, never a fourth summary child. A parent detail “语音拆解” uses the same preview for that parent without cloning it. Quick add and parent decomposition are explicit contexts of this same machine. Cancel, Escape, pointercancel, lost capture or leaving the page restores the pre-session data, kills timers and returns to Idle. After accepted Done, bars settle and the new record is selected in detail. No microphone, network or personal data access.

## Typography, materials and optics
Use exactly the native stack -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text"; no webfont. Mobile hero 30px/650/39px, body17/450/25, title17/600/25, meta13/500/19. Desktop hero38/620/48, body15/450/23, control13/550/19, meta12/450/18. These are size/weight/line-height triples. Spacing base4, atom4, row padding16, section32, hero-to-pocket minimum96. Use at most four sizes per pane. CJK wraps; changing counts use tabular numbers, never ellipsis or numeric truncation.

Light: L0 #F3F8FA, L1 #F7FAFC, L2 #FFFFFF; ink #172C3C, secondary #526675, action #086987, success #226847. Dark: L0 #101B24, L1 #15212B, L2 #1B2A35; ink #EDF7FA, secondary #A8BEC9, action #79DCEE, success #8FD9B1. Light is dark ink on luminous paper; dark is pale ink on deep blue, not a photo-negative white sheet. Primary text must achieve 4.5:1; large hero 3:1. Only P0 ring and active selection receive saturated emphasis.

Separate three physical layers: broad ambient cyan radial aura behind the pocket at 12% light/9% dark opacity; transparent optical pocket shell; opaque content well and undistorted controls above. Functional shell uses blur(28px) saturate(190%) and -webkit-backdrop-filter with the same values; light tint rgba(255,255,255,.30), dark rgba(30,57,72,.40). Fresnel top inset 0 1px 0 rgba(255,255,255,.75); outer shadow 0 16px 40px rgba(20,59,80,.15), fine rim rgba(255,255,255,.28), radius32 mobile/24 desktop. Do not blur the task text or sample another glass layer. Optional Chromium Snell/Fresnel samples background only with displacement <=3px at the rim; disable it in WebKit. HTML is an optical approximation, never claim native glass rendering. Reduce Transparency or unavailable backdrop support replaces the shell with opaque L1 and a quiet solid rim.

## Safety and implementation acceptance
Mobile targets >=44×44px; desktop >=28×28px with invisible padding, not ruler boxes. Use visible 2px focus rings and 3px offsets, logical Tab order, arrow keys in filter menus, Escape for menus then sheets, and focus trapping/inert background only while a modal sheet is open. Motion honors prefers-reduced-motion with instant geometry and 80ms opacity; bars become static. Announce state transitions once through a polite status region, never seven individual bars. Keep scroll padding above accessories and test 200% type using scrolling rather than clipping. Preserve scaffolder page-config and trusted outer theme/platform postMessage hooks; only outer chooser may change appearance/platform/selection. Do not add inner website headers, Active/Matte debug controls, 28×28 rulers, footer disclaimers, raw checkbox inputs, rich-r3.css, .caustic-veil or repeating-linear-gradient stripes. Native app navigation is permitted. The native back-to-capture button opens an in-document recording-home state copied read-only from baseline/original/v02.html and baseline/interactive.html: zero top capsule, huge whitespace/single sentence, bottom glass sheet, hold/release seven bars and bottom-leading Fold unfolding Todo List and Settings. Recording home uses the same synthetic hold/tap/release/cancel lifecycle, showing only the refined sentence until Todo explicitly requests decomposition. Never modify baseline files or link local file URLs. Verify both viewport sizes in light/dark, all filters, complete/undo, detail/back, voice hold/tap/cancel, exact-three preview and runner stop/retry; rendered validation belongs to Stage 2, not this prompt receipt.
