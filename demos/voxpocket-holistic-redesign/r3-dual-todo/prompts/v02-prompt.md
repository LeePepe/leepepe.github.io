## Intent: a river of tasks, not cards
Make the Todo workspace read as one calm stream of text whose priority is expressed by luminance and pauses. The only focal P0 is its first anchored action, “汇总云桥样稿的修改”. Avoid enclosing each row in a tile. Coordinate lock: VS-005 Zen Paper Checklist, CL-006 cool paper with restrained CL-003 sonic accents. X: P0 first task completion; P1 continuous list and voice-add edge; P2 status menu and selected-task disclosures; P3 execution receipt in detail. Y: a continuous list interrupted by one large breathing gap, with details replacing rather than stacking content. Z: solid luminance stream beneath a single full-width functional capture sheet. This is a self-contained HTML sandbox prompt, not a production theme freeze.
