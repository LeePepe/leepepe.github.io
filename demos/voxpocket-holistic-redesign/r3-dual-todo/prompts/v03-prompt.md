# v03 — Voice-Decomposed Action Tree

## Design proposition
A spoken intention becomes a small living branch. The layout must make causality visible: original sentence, exactly three actions, then one execution rail. This is not a checklist dressed with connector lines. P0 is the original intention “为纸舟展览准备一份导览”; its children are subordinate. Coordinate set: VS-003 Precision Acoustic & AI Studio, CL-003 deep slate/sonic cyan with a luminous light counterpart. X: one parent focus/complete; P1 branch disclosure and quick voice; P2 sibling tasks and status scope; P3 notes/runner receipt. Y: one expanded branch, siblings in a folded side root. Z: solid tree content and a narrow glass functional stem. Use native mobile Sheet and desktop Inspector, not website navigation. Author a self-contained interactive HTML sandbox later from this prompt alone.

## Working tree model
Fictional sibling tasks: “核对星野海报” pending; “编写微风摘要” running; “归档月砂手册” done. The status menu “全部 / 待处理 / AI 执行中 / 已完成” filters the sibling navigator only; the fixed P0 intention and its children are separately scoped and never duplicated in siblings. Empty scope offers “显示全部”. Parent selection, child selection and completion are distinct operations. Child row text opens detail; its custom circular completion button uses aria-pressed. Parent completion stays explicit, even after three children finish. Parent state can be reopened and Undo restores all prior task states exactly.

On completion, the check stroke draws120ms, connector segment softly changes to success color over200ms, row ink retreats to70% for240ms. No confetti, no springy shaking. Completed items remain locatable; filtering can remove them only after focus is moved to the next visible node. Parent Undo appears as quiet text for5s and persists in detail. Use a single state store so inspector, filter counts and tree all agree.

## Capture, decomposition, execution
In Idle, the parent contains “拆成三步” text action and a sparse placeholder branch, not three arbitrary generated rows. Activate it to start the same synthetic capture machine used by quick add, but with update-parent context. Hold voice>=160ms to enter Listening; release enters Refining (1000ms); Done reveals exactly3 child action items in a preview. Short tap toggles listening/stop; held focused Space mirrors hold/release and Enter toggles without requiring timing. Ignore key repeats and suppress post-hold clicks.

Transcript: “准备纸舟展览导览：挑选三件展品，写各自介绍，排成一页路线”. Child labels are exactly “挑选三件示例展品”, “为每件展品写介绍”, “排成一页导览路线”. Preview shows original sentence and three branches with “应用三步”/“重说”. Applying commits once and exposes the tree; quick voice add instead creates a new parent holding that same exactly-three child set and opens its detail, without replacing the existing P0 automatically. Further decomposition asks whether to replace an existing generated set. No duplicate children, no fourth summary row. Cancel/Escape, pointercancel, lost capture, page exit and cancel during refinement all restore the pre-session model and invalidate timers. Done is not automatic execution.

“运行这三步” inside runner disclosure deliberately begins the local AI runner: 待命 → 排队(300ms) → 第1/3步运行 → 第2/3步运行 → 第3/3步运行 → 完成, 750ms each. A small runner caret tracks the active branch. Stop changes to 已暂停 without altering completion rings; Continue resumes from the stopped branch, Retry resets the simulated execution receipt. A “模拟失败” option is available only in the runner overflow menu for deterministic failure/retry testing, not as a global debug bar. Running status reads “本地演示执行”, not a false real-agent connection. No microphone, network, clipboard, account or personal-data calls.

Changing runner numbers are tabular; no clipped or abbreviated numbers. Permit CJK line wrapping and 200% type with local scrolling, not whole-tree shrink-to-fit.

Light canvas L0 #EDF5F8, reading L1 #F4F9FB, selected L2 #FFFFFF, ink #173142, secondary #4F6675, cyan #076A86, success #216948. Glass belongs only to lower voice stem, toolbar and transient grabber. Ambient layer: one large radial cyan aura centered below the stem, opacity.14 light/.10 dark.
