BAMA：预算感知多智能体路由、Agent CLI 与免 GUI 故事验收架构

BAMA 不是让大模型盲猜整个 macOS 工程，而是用「按需技能路由（0 上下文闲置开销）+ 应用内建 Socket CLI + 1 Story = 1 Commit 快照门禁」把 GUI 开发拆成确定性流水线 —— 21 个分阶段微技能与 --help 即时发现机制让日常上下文 Token 预算降低 80% 以上，并通过单写者 Socket 保证 CLI 与窗口 100% 状态同步。

核心痛点问答#

Q1. 为什么多智能体写 macOS 应用越写越贵、上下文越跑越偏，BAMA 如何实现预算感知路由？#

  • 直答：把全流程拆成 5 个阶段（Start → Plan → Code → Design → Ship）共 21 个正交微技能，由顶层 /bama 路由器按当前磁盘产物（如是否存在 docs/BRIEF.md、docs/STORIES.md）单步派发，且应用交互通过 --help 零驻留 CLI 驱动。
  • 原理与教具：传统做法像背着 20 公斤全套修理箱去拧一颗螺丝，每次对话都要重读几万字规范；BAMA 像胶囊咖啡机——平时外部 CLI 和非当前阶段技能占 0 Token，只有轮到 research 时才扇出并行子代理（市场/用户/功能/设计/macOS API），轮到日常操作时 Agent 只需执行 <cli-name> --help 即可按需获知参数。

Q2. BAMA 怎样把静态「页面截图清单」变成免 Xcode GUI、可由 Agent CLI 逐步验收的用户故事？#

  • 直答：先用 clone 生成页面索引 docs/screens/INDEX.md，再用 user-stories 将每个画面映射为「单动作 + 四类强制验证前缀（[snap] / [unit] / [self] / [manual]）」的故事卡，并内建 --snapshot 快照模式与 agent-cli 调试桥。
  • 原理与教具：屏幕截图只告诉你“长什么样”，故事才定义“人做什么”。就像把建筑效果图拆成带验收标准的施工水电单：
    • [snap]：启动无头快照模式渲染浅色/深色 PNG，并用 measure.swift / compare.swift 做 4pt 网格与像素级比对；
    • [self]：通过应用内建自检桥验证交互（如“5 秒内显示 Undo 横幅，按 Cmd-Z 可撤销”）；
    • [unit]：纯逻辑抽离 @MainActor Store，用 Swift Testing 独立秒级验证。

Q3. 为什么 Agent CLI 严禁直接读写应用的 SQLite / SwiftData 数据库文件，而必须通过私有 Socket 转发给运行中的 App？#

  • 直答：双写者直接改库会绕过业务校验、破坏 SwiftData 内存上下文缓存，并导致已打开的 macOS 窗口无法实时刷新；走私有 Socket 能保证 唯一写者（Single Writer） 与 UI 零延迟同步。
  • 原理与教具：直接改数据库文件就像半夜翻窗进仓库改账本——前台店员（正在运行的 App 窗口）毫不知情，手里的旧账本一保存就会互相覆盖报错。而 BAMA 的 agent-cli 把命令发给 App 内部监听的 Socket，直接调用和窗口按钮完全相同的 Model 函数，还会将操作分级为 read、write 和必须带 --yes 才真正执行的 destructive（否则只預览影响范围）。

Q4. 当业务迭代导致文件膨胀、状态高频抖动时，improve-architecture 用什么量化指标触发重构？#

  • 直答：设定了 6 条硬性触发红线与 「删除测试（Deletion Test）」，每次重构严格限制在 1 个 Commit 证明行为不变（≤10 个文件）。
  • 原理与教具：不必等代码腐化到无法维护才重构，只要命中以下任意一条即刻启动体检：
    1. 单 Swift 文件超过 600 行（1,000 行强制拆分）或单个类型超过 400 行；
    2. 单个功能改动跨越 >6 个文件或 >2 个 Target；
    3. 同一区域在 FIXLOG.md 重复出现 3 次，或状态每秒变化 >10 次却挂在全局观察对象上。

    判断模块该不该留只需做「删除测试」：删掉它后，如果复杂度集中在 1 处就保留该深模块（Deep Module），如果只是传声筒（Pass-through）则立即内联消除。

立即可用清单#

  • 给用户故事加上四类可检验前缀：编写 spec.md 或 STORIES.md 时，强制每条验收标准以 [snap]（浅/深色快照）、[unit]（纯值单测）或 [self]（CLI/自检桥）开头，淘汰一切“体验流畅/正常工作”的模糊描述。
  • 用单写者 Socket CLI 替代脚本直改数据库：为本地 macOS 工具提供 Agent 接口时，复用窗口按钮同源函数暴露 read / write / destructive (--yes) 三级命令，返回精简 JSON 与 8 位短 ID。
  • 设置 600 行与 10 Hz 状态刷新架构门禁：在里程碑收口时扫描 wc -l 超 600 行的热点文件，将 @MainActor Store 中的纯计算逻辑剥离为不依赖 UI 的纯值 Struct（Deep Module）。
