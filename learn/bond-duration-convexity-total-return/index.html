债券久期不是到期时间：利率冲击下的总回报与凸性

久期不是“还有几年到期”，而是债券全部未来现金流的现值重心；利率上升 1 个百分点时，修正久期约 7 年的组合先损失约 7%，票息与凸性再把这张账单部分拉回。

现金流重心决定了利率敏感度#

把债券想成一串未来到账的红包：零息债只有到期日一个大红包，现金流重心靠后；高票息债不断提前发小红包，重心被拉向今天。债券价格是这些红包按收益率折现后的总和，因此收益率上升，相当于把远处红包打更大的折扣，长久期债券先受伤。

如果一个债券组合的修正久期是 D = 7，收益率从 4.00% 上升到 4.50%，即 Δy = 0.005，一阶估算为：

ΔP/P ≈ -7 × 0.005 = -3.5%

这不是“持有七年就不会亏”的保证，而是今天价格对利率瞬时变化的斜率。到期时间只是一个日期，久期才是风险暴露的重心。

总回报是一张三栏账，而不是只看净值#

债券投资者在持有期内同时面对三项：价格因利率变化产生的资本利得/损失、收到的票息、票息再投资的收益。用一年持有期做简化账本：

总回报 ≈ 价格变化 + 票息收入 + 票息再投资收益

因此，短期利率冲击可能令净值先跌，但高票息会持续“进水”；若持有期拉长，较高收益率还会提高新收到现金的再投资回报。评价债券基金不能只截取一次加息日的价格跌幅，也不能把票息当成能立刻抵消久期损失的护盾。

凸性为什么让大幅变动不能用直线硬算#

价格—收益率关系不是直线，而是向上弯曲的曲线。加入凸性后：

ΔP/P ≈ -D×Δy + ½C×(Δy)²

假设 D = 7、C = 60、收益率上升 150bp：

  • 久期项：-7 × 0.015 = -10.50%
  • 凸性修正：½ × 60 × 0.015² = +0.675%
  • 合计约：-9.825%，比只用久期的估算少跌约 0.675 个百分点。

凸性不是免费收益，也不是所有债券都一样；可赎回债券的现金流会随利率改变，不能简单套用普通固定利率债的正凸性。CFA Institute 的复习材料也把“久期是一阶近似、凸性是二阶修正”作为组合利率风险的基本边界。

核心痛点问答#

到期时间越长，久期一定越长吗？#

不一定。票息越高，越多现值提前回收，久期可能低于到期时间；带期权的债券还会出现有效久期随利率变化。

利率上涨时，债券一定亏钱吗？#

短期价格通常承压，但总回报还包含票息与再投资；真正要问的是持有期、久期、票息和利率路径是否匹配。

“持有到期就没有利率风险”对基金成立吗？#

对单只债券，持有到期可以把本金和票息路径锁得更清楚；债券基金不断买卖、没有单一到期日，净值仍会随市场利率变化。

立即可用清单#

  • 先看久期再看“债券”标签：把收益率变动 50bp、100bp 代入 -D×Δy，先得到压力测试的一阶结果。
  • 把总回报拆三栏：分别记录价格、票息、再投资，不用单日净值变化替代持有期回报。
  • 大幅利率情景加凸性：久期只适合小变动；遇到 100bp 以上冲击或长久期组合，加入 ½C×(Δy)²，并检查是否含嵌入期权。
