为什么再平衡不是越勤越好：阈值、交易摩擦与波动收割的数学边界

再平衡赚的不是“每次卖高买低”的免费收益，而是用可控的漂移换取交易成本、税费与错过趋势之间的折中；当组合偏离还没有跨过成本阈值时，最优动作往往是“不动”。 以 60/40 组合为例，月度强制归位会把每一次小波动都变成交易，而 200/175bp 阈值策略可以把平均交易成本压低到日历策略的约三分之一至四分之一。

一、再平衡为什么会有收益：把它看成“逆着权重漂移交易”#

设股票目标权重为 w* = 60%，当前权重为 w = 63%。如果股票随后下跌，组合先前多持有的 3 个百分点会放大损失；卖出一部分股票、买入债券，相当于把风险暴露拉回预先设计的水平。反过来，若股票持续上涨，过早卖出也会放弃趋势收益。再平衡因此不是预测市场，而是把组合重新绑回风险预算。

可以把它想成两个水池：股票池进水快、波动大，债券池进水慢、波动小。水池水位自然会漂移；只有当水位越过警戒线，抽水机才值得启动。每次启动都付出固定电费（佣金、买卖价差、税费），所以“每天纠偏”并不等于“每天增加收益”。

二、为什么频繁归位会吃掉波动收割#

再平衡的简化净收益可以写成：

Net = Δrisk_control + Δmean_reversion - Ctrade - Ctax - Copportunity

其中 Δrisk_control 是把风险维持在目标区间的价值，Δmean_reversion 是波动带来的低买高卖机会，后三项是交易成本与机会成本。日历策略每月或每季固定执行，优点是简单；缺点是在组合几乎没有漂移时仍然强行交易。

Vanguard 的阈值研究显示，200/175bp 的策略相较月度、季度日历策略，平均交易成本更低，年化相对收益约高 11–18bp；另一项分析也提醒，较小阈值虽然降低跟踪误差，却会显著提高交易次数。这个数字不是“再平衡必然赚钱”的承诺，而是说明成本项足以改变最优策略。

三、怎样把“偏离多少”换成可执行规则#

先算当前权重：

w_i = market_value_i / total_portfolio_value

再算漂移：

d_i = w_i - w_i*

最后把每类资产的交易成本写成同一张表：

项目估算方式何时必须纳入
显性费用申购/赎回、佣金、平台费每笔交易
点差与冲击成交价 - 中间价流动性差、金额大
税费应税资本利得或分红非免税账户
机会成本卖出强势资产后继续上涨的收益趋势强、偏离仍小

一个可落地的默认策略是：每月只检查一次，每年或当任一大类资产偏离目标 2 个百分点时才交易；交易时优先用新现金流补低配资产，不先卖出刚买入、税费或赎回费最高的份额。

核心痛点问答#

Q1. 为什么 60/40 不是“股票涨了 1%，就卖一点股票”？#

  • 直答：因为 1% 价格变化不等于 1% 权重漂移。水池总水量也在变化，必须先计算 w_i，再判断 d_i 是否越过阈值。

Q2. 阈值设得越小，风险就越安全吗？#

  • 直答：跟踪误差会更小，但交易成本会更高。像把恒温器死区设成 0.01℃：温度更贴刻度，压缩机却可能一直启停。

Q3. 200/175bp 是通用答案吗？#

  • 直答：不是。它是一个成本—漂移折中范例。应按资产波动、税费、流动性和可接受最大风险漂移重新校准；高波动资产可能需要更宽阈值，税费高的账户可能更依赖现金流再平衡。

Q4. 再平衡是不是在预测均值回归？#

  • 直答：不需要。它首先是风险预算纪律，均值回归只是可能的附带收益；如果把它当作必然低买高卖，就会在强趋势中卖得过早。

立即可用清单#

  • 把“检查频率”和“交易频率”分开：每月记录权重，每次只有当漂移超过预设阈值才下单。
  • 建立成本底表：把佣金、点差、税费和赎回费换算成基点；若预计纠偏收益小于成本，保持不动。
  • 优先用增量现金流纠偏：工资、分红或到期资金先补低配资产，减少卖出带来的税费与趋势机会成本。

来源与边界#

本文的阈值与成本数字来自 Vanguard 的阈值再平衡研究；实际结果取决于市场路径、税制、账户类型与执行成本，不构成个性化投资建议。
