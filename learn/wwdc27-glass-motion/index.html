核心痛点问答#

Q1. 从 OS 26（WWDC25）到 OS 27（WWDC26），Liquid Glass 和容器交互到底进化了什么？#

  • 直答：OS 26 解决了「把导航栏变成悬浮液态玻璃」，而 OS 27 解决了「当所有窗口都能任意拉伸缩放、甚至在 Mac 上用鼠标点按时，玻璃和工具栏如何优雅自适应」。
  • 原理与演进对照：
维度OS 26（WWDC25 初代奠基）OS 27（WWDC26 二代进化）
玻璃触控与鼠标交互.interactive() 仅在 iOS 上提供手指按压弹性缩放与内发光流转macOS 全面支持 .interactive()，针对鼠标指针与点击优化了微弹跳反馈
窗口形态假设iPad/Mac 可缩放，iPhone 仍以固定屏幕尺寸和横竖屏为主iPhone 应用全面支持自由窗口缩放（Mac iPhone Mirroring 与 iPad 运行），严禁再用 idiom/orientation 算布局
工具栏与 Tab 栏拥挤度ToolbarSpacer 分组、.tabBarMinimizeBehavior(.onScrollDown)新增 visibilityPriority(.high)、ToolbarOverflowMenu、.topBarPinnedTrailing、Tab(role: .prominent) 与导航栏随滚动收起
窗口焦点与菜单降噪玻璃在窗口失焦时自动视觉后退新增 @Environment(\.appearsActive) 供自定义视图同步降暗；菜单栏默认隐藏次要图标
列表交互解绑.swipeActions 与拖拽重排强绑定在 List 上彻底解绑 List：.reorderContainer 与 .swipeActionsContainer 让 LazyVStack/LazyVGrid 拥有同等丝滑交互

Q2. 这 8 节课我没时间全看，按当前手头的研发任务怎么挑最急需的？#

  • 直答：按你正在写的层级（导航壳层 vs. 画布动效 vs. 列表拖拽 vs. 跨端容器）对号入座，每次只看 1 张卡片（10 分钟）。
  • 原理与教具：
    1. 改全局导航、Toolbar、Sheet 和玻璃按钮 → 直接看 liquid-glass-optics-and-swiftui-26-27.md（对应 219 + 323 + 269 前半段）；
    2. 做封面流体背景、实时音频/歌词联动、复杂边缘角标 → 直接看 swiftui-27-shader-and-motion-pipeline.md（对应 322）；
    3. 修长列表滚动掉帧、做看板/卡片多选拖拽排序 → 直接看 swiftui-27-scrolling-and-drag-drop-motion.md（对应 321 + 271）；
    4. 维护 macOS AppKit 工程或含 UIKit 的跨端宿主 → 直接看 appkit-uikit-27-modernization.md（对应 289 + 278）。

Q3. 为什么 OS 27 突然把编译速度和运行时内存同时提升了好几个量级？#

  • 直答：因为 SwiftUI 在 OS 27 动了两个底层手术——把 @State 变成了 Macro（消除每次父视图刷新时白建 @Observable 实例），并把 ViewBuilder 等合并成了 @ContentBuilder（消除嵌套泛型指数级分支试错）。
  • 原理与教具：以前写 @State private var store = StickerStore()，父视图每刷新 100 次，StickerStore() 就会白白实例化 99 次再被丢弃；现在 @State Macro 把它包成惰性闭包，整个生命周期只创建 1 次（且回溯兼容到 iOS 17 / macOS 14）。同时 AsyncImage 默认接管了标准 HTTP URLCache，往回滚列表再也不会闪烁重载。

Q4. Xcode 27 提到的内置 Agent Skills 怎么导出来给本地 CLI 工具（如 Claude / Codex / Copilot）用？#

  • 直答：在终端执行一行命令 xcrun agent skills export，即可把 Apple 官方内置的 SwiftUI 与 UIKit 现代化技能导出为标准 Markdown 文件。
  • 原理与教具：WWDC26 Session 269（27:16）与 Session 278（15:05）同时揭晓了 Xcode 27 Coding Assistant 内置的三大官方技能——SwiftUI Specialist Skill、What's New In SwiftUI Skill 与 UIKit App Modernization Skill，通过 xcrun agent skills export 即可直接接入你的本地 Agent 工作流。

立即可用清单#

  • 先撤掉旧背景遮罩再加玻璃：升级 Xcode 26/27 SDK 后，第一步不是到处加 .glassEffect()，而是删掉以前手写的 Toolbar/Sheet 半透明黑底和 .presentationBackground，让系统原生 Liquid Glass 与自适应 Scroll Edge Effect 自动接管。
  • 用 GlassEffectContainer 包裹相邻自定义玻璃控件：凡是有两个以上相邻或需要流体展开/收拢的自定义玻璃组件，必须放进同一个 GlassEffectContainer 共享光学采样区，并挂上 .glassEffectID(_:in:)。
  • 全局排查 3 个历史包袱：在 SwiftUI 中去掉 @State 属性声明与 init 双重赋值；在 LazyVStack 叶子视图中把 if 过滤移到数据源 #Predicate；在 UIKit/混合工程中用 Size Classes 与 traitCollection.displayScale 彻底替换 UIScreen.main 和 userInterfaceIdiom。

延伸视野#

  • 从「命令式画皮」到「声明式物理场与数据流」：纵观这 8 节课，Apple 正在把过去需要几百行手写几何计算与事件循环的工作（玻璃折射、多卡堆叠拖拽、窗口同心圆角、歌词时间轴同步），全部收敛为「声明意图 + 交给系统物理引擎与 GPU 管线」。工程师的核心竞争力不再是手搓 mouseDown 或手算 CGRect 偏移，而是设计干净的数据管道与准确的层级语义。
