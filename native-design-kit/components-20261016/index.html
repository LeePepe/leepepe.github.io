组件具体发现与修正本轮视觉结论
Button修正加载占位不对称、桌面加载环过大、大字体进度挤压文字，以及浮动 Glass 遮挡文稿。现在文字居中、加载槽稳定，中文完整换行；Glass 与下方内容留出间距。所示静态状态通过。真实录像呈现按压、加载及完成；运行测试另证禁用与重复操作阻止。
Toggle保留原生 switch，统一尾部对齐，去掉重复禁用透明度。中文标签及辅助说明自然增长，开启／关闭可由拇指位置辨别。所示静态状态通过，无剩余阻断问题；录像呈现真实切换及对应状态文字。
TextField移除重复输入框 chrome，补齐持久标签；修正小于目标的原生 bezel 周围无法聚焦的问题。最终修正空提交后错误被键盘遮挡：完整原因与修正方法滚动到键盘上方，保留焦点。重拍已移除首次键盘教学弹层。所示静态及错误反馈通过；录像呈现焦点、空提交错误、输入 Draft 与 Return 提交。

未覆盖情况

这些截图证明对应时刻的呈现；录像与测试证明其实际执行路径。它们不构成全平台或完整无障碍认证。

  • macOS 是 480 × 1000 pt 的 NSHostingView 位图，使用明确标注的 bordered fallback，非实时 Glass；非活动窗口的中性开关轨道不能证明真实活动窗口 tint。macOS 强制大字体图片没有可见字号增长，不作为桌面大字体通过证据。
  • 完整桌面 XCUIAutomation 未成功启动；hover、Tab／快捷键／完整键盘导航、实时 focus ring 和桌面 Glass 尚未验收。较窄的原生宿主事件测试不能替代这些检查。
  • 未运行 VoiceOver、Full Keyboard Access、Increase Contrast、Reduce Motion／Reduce Transparency 系统设置或最低 iOS 15／macOS 12 设备。源码的原生语义与 fallback 分支不等于设置或旧系统运行通过。
  • 未测量原生 bezel、placeholder、Glass 的实际渲染对比度；原生 placeholder 较淡，由持久标签和 helper 提供用途说明。输入法组合、长文本完整选取／横向滚动及大字体下的键盘错误提示仍未专项验收。
  • 录像抽帧复核支持所示状态顺序与布局，不能证明连续动效、精确响应时间或无触点标记的实际点击位置。三段录像仍保留少量启动／退出画面。真实交互录屏为 iPhone 浅色；深色与大字体提供独立状态板。改前／改后使用相同系统、设备、视口和 provider，但展示内容随设计增加持久标签、说明和最小上下文。
