MP-001 · gesture-physical

卡片揭角 (Card Corner Peel)

web, mobile, shared · motion-interaction, visual-style, component

做一张可揭角的卡片，右下角按住后随拖动卷起，用折线裁切正面并露出背面，折片带柔和明暗。松手沿原路回落，短距离拖动只露一角，整张卡片保持稳定。

实现与防呆护栏

SwiftUI `.onContinuousHover` for corner curl preview plus pointer `DragGesture` driving a custom `Shape` or `Canvas` clip path and `.visualEffect` / Metal `ShaderLibrary` crease shading; settles with native `Animation.spring(duration: 0.38, bounce: 0.15)` while keeping the outer card frame locked inside its `NSWindow` or `NSPopover` grid.

Zero layout shift (card bounds never jump); `.monospacedDigit()` on any revealed numeric metrics; >=4.5:1 foreground/background contrast in Light and Dark mode using semantic `Color.primary` / `Color(nsColor: .controlBackgroundColor)` / `Color(uiColor: .secondarySystemGroupedBackground)`; >=44x44pt corner hit target on iOS and >=28x28pt on macOS; `@Environment(\.accessibilityReduceMotion)` replaces peel geometry with a direct `.opacity` crossfade; `@Environment(\.accessibilityReduceTransparency)` replaces translucent back-card layers with opaque system surfaces.

MP-002 · confirmation-safety

滑动确认 (Slide-to-Confirm)

web, mobile, shared · motion-interaction, component, typography-copy

做一个滑动确认按钮，圆钮与轨道填充跟随同一拖动进度。未到终点松手，阻尼回到起点且不执行；到终点松手才确认，箭头变成对勾，文字变为已完成。

实现与防呆护栏

SwiftUI pointer `DragGesture` (plus keyboard `Return` / `⌘Return` confirmation equivalent) binding a single normalized progress `CGFloat` (`0.0...1.0`) to both the thumb offset and track fill width; commits only when released at `progress >= 0.95`, morphing SF Symbols (`arrow.right` to `checkmark`) via `.contentTransition(.symbolEffect(.replace))` and settling with `Animation.spring(duration: 0.3, bounce: 0.1)`.

No accidental commit below threshold; >=44x44pt thumb hit target on iOS and >=32x32pt on macOS with full keyboard accessibility (`accessibilityAction`); >=4.5:1 text and icon contrast against both unfilled and filled semantic `Color.green` / `Color.accentColor` tracks in Light and Dark modes; `@Environment(\.accessibilityReduceMotion)` disables spring oscillation and uses instant state/opacity transition; `@Environment(\.accessibilityReduceTransparency)` backs the track with solid `Color(uiColor: .tertiarySystemFill)`.

Strictly one toggle per pull cycle with bounded vertical drag distance; state is never communicated by glow alone (always pair with explicit SF Symbol `lightbulb.fill` / `lightbulb` and semantic label); >=44x44pt hit target on iOS and >=28x28pt on macOS; >=4.5:1 contrast in Light and Dark appearances; `@Environment(\.accessibilityReduceMotion)` eliminates pendulum swing and snaps the cord smoothly; `@Environment(\.accessibilityReduceTransparency)` uses opaque warm surface fills.
