V2：先把布局和行为做对

用户校正：主题色独立；上一轮布局全部不采纳；密度不足。保留当前产品的可用结构，改细节和性能。动作选择保留侧栏＋双列，搜索、filter 和确认操作在底部。训练是本轮重点。

仅在 Prototype 实现并比较，不改生产 AppUI / 数据合同。统一使用 DesignKit blue/slate、相同字体、圆角与间距，浅深色只作适配检查。旧风格矩阵不参与这轮选型。

三种训练布局

布局 内容组织 价值与代价
A 当前动作表格 顶部一行动作标签；选中动作完整组表；下方紧凑其他动作队列 接近当前训练习惯；上次、重量、次数、完成同一行。跨动作比较需要切换
B 侧栏工作台 固定 64pt 动作轨道；右侧选中动作组表 大屏切动作路径稳定；窄屏省去上次列，历史与输入辅助进入键盘
C 全计划组矩阵 每个动作一行标题＋每行四组单元格；全计划持续滚动 16 组可在一屏近乎全览，点任意组开始编辑；上次记录与完整元数据放入键盘 / More

三者的状态、按钮和输入语义相同。不得用隐藏功能或缩小触控目标来制造紧凑。

每块区域的作用与行为

区域 负责 行为边界
训练头部 64pt 名称、固定演示时长、完成数、容量、未连接状态 只读，不摆大标题卡、重复进度条、结束按钮；原型无真实传感器
动作导航 选择当前动作，显示动作内进度 切换有效草稿先保存，不记组；无效输入阻止切换并保留修正入口
组记录 编号、类型、上次、重量、次数、完成 数字点按编辑；完成键只作用于明确选择组。允许编辑已有任意主组；不强制只改首个未完成组
状态槽 44pt none / rest / undo 互斥 高度恒定，撤销优先而休息继续；倒计时只在独立子视图更新
底部动作区 More、加组、完成本组 只保留高频操作；结束训练在 More 训练域，需确认
键盘字段条 重量 / 次数选择、保存并收起 打开全选，切换保留草稿；收起只保存，不记组
键盘辅助条 上次、复制下组、RPE、组类型、More 输入相关操作，选择对象始终是当前草稿绑定的组
键盘数字 / 扩展区 188pt 数字输入，或 RPE / 类型面板 在原区域替换，辅助面板不把整页再顶高；RPE / 类型随输入一起保存或放弃
More 按当前组 / 当前动作 / 整次训练分组管理 不把所有功能平铺到主屏。删除可撤销，替换进选择器，结束需确认；高级生产功能的位置明确但未接入

动作选择

固定 64pt 器械侧栏作为分区跳转，不将导航偷偷改成过滤。结果保持两列，普通卡最小 76pt，去除巨型图标占位。顶部仅标题和结果数量。

底部两行：搜索字段＋Filter；取消＋已选顺序清单＋确认。Filter 从底部抽屉打开肌群 / 器械选项。搜索结果变动不卸载 TextField 或 ScrollView；选择 / 反选不重算筛选结果。保留 200ms debounce 与缓存分组。大字号可退单列以保持阅读，但常规 375/393pt 均保留侧栏＋双列。

性能职责

原型缓存搜索输出；输入只更改草稿，提交才改组数据。统计、行、键盘、休息为独立 View 观察边界；不将全页包在 TimelineView 内。结果只有一层 lazy 容器，内部有界行 eager。底栏不测量内容高度来回驱动网格布局。

生产风险来自真实代码，见 源码性能审计：重复历史 fetch、冗余 keyboard rootView 更新及重复聚合。原型没有生产数据库、UIKit inputView 或 Release trace，不能声称生产卡顿已修复。

验收

实际渲染 3 布局 × 6 状态（键盘开关 × none/rest/undo）× light/dark。另看 More、RPE、选择器、筛选、无结果与375pt布局回退。独立设计评审必须针对本次紧凑要求、区域职责与触控目标给 /35 + P0/P1，旧评分作废于本轮。

验证选中任意组、草稿随保存 / 放弃、输入无效阻止导航、RPE / 类型一起提交、跨筛选选择与搜索缓存。所有屏幕都是明确标注演示数据的原生 SwiftUI；macOS ImageRenderer 不冒充 iOS Simulator、VO 或性能验收。
